Scope of delivery

Everything in the brief. Plus the platform behind it.

The visualizer you just used isn't a one-off. It's the first instance of a modular platform — add a new model, a new market, or a new campaign without rebuilding anything.

01
360° exterior in all 15 colours
~36 frames per colour. Drag-to-spin on desktop, swipe on mobile. Preloaded for instant response.
02
Interior panorama
1 interior colour, full panoramic view. Transitions cleanly from exterior with a single tap.
03
Colour-reactive environment
Background atmosphere shifts per exterior colour — the Renault R5 effect, built in from day one.
04
AEM HTML snippet — drop-in
One script tag, one data attribute. Slot into any AEM component or PIP highlight section.
05
Fully themeable CSS
Every colour, font, and size is a CSS variable. HME's agency reskins it without touching logic.
06
Modular data layer
New model = new database rows. No code changes. IONIQ 5, Nexo, Santa Fe — all reuse the same platform.
