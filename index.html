Scope of delivery

Everything in the brief. Plus the platform.

The visualizer above isn't a one-off. It's the first instance of a modular platform — add a new model, market, or campaign without rebuilding anything.

01
360° exterior in all colours
36 frames per colour, drag-to-spin. Preloaded for instant response.
02
Equirectangular interior panorama
Full WebGL pano per interior colour. One tap from exterior view.
03
Colour-reactive atmosphere
Stage tint shifts per exterior colour — the Renault R5 effect, built in.
04
AEM HTML snippet — drop-in
One script tag, one data attribute. Slots into any PIP highlight section.
05
Themeable CSS
Every colour, font, and size is a CSS variable. HME reskins without touching logic.
06
Modular data layer
New model = new config file. IONIQ 3, Nexo, Santa Fe — same platform.
